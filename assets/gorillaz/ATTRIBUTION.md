# Gorillaz test assets

`island.png`, `band.png` and the Tiled project alongside them (`island.tmx`,
`island.tsx`, and the `.tiled-project` / `.tiled-session` files) are original
artwork and level data created by Kris Holdich for Blits Per Second. They are
first-party engine assets, not extracted from another game or system.

The directory name is a project codename and carries no claim on, or
connection to, anything else of that name.

Used by `examples/tmx.py` (the tilemap pillar), `examples/layers.py` and
`examples/gamepad.py`.
